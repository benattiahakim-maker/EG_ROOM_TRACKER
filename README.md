# EG_ROOM_TRACKER

Composant C# pour Autodesk Platform Services — Design Automation for Revit 2025, 2026 et 2027.

Extraction des pièces d’une maquette RVT reçue dans un ZIP : identité, nom, numéro, surface, hauteur non bornée, niveau, occupation, volume et finitions.
